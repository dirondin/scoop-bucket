# Scoop bucket for Varstotas

[Varstotas](https://github.com/dirondin/varstotas) is a free, open-source 3D modeller for makers:
furniture, workshop projects and 3D prints, in real units.

```powershell
scoop bucket add dirondin https://github.com/dirondin/scoop-bucket
scoop install dirondin/varstotas
```

This installs the portable build (a Start menu shortcut "Varstotas" in Scoop Apps and the
`varstotas` command). Update with `scoop update varstotas`. For an installer with the `.vrst` file
association, use `winget install Dirondin.Varstotas` or the setup from the
[releases](https://github.com/dirondin/varstotas/releases).

The manifest is updated automatically by the Varstotas release workflow; please report problems in
the [main repository](https://github.com/dirondin/varstotas/issues).
